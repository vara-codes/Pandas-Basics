# ❤️ Cardio AI Patient Data Cleaning with Pandas

A beginner-level healthcare data cleaning project built using **Python**, **Pandas**, and **NumPy**.

## 📌 Project Overview

This project demonstrates fundamental data preprocessing techniques on a simulated cardiology patient dataset.

## 🩺 Features

- Create a DataFrame
- Detect missing values
- Handle missing data using the mean
- Find duplicate patient records
- Remove duplicates
- Create a RiskScore column
- Sort patient records
- Filter high-risk patients
- Count patients by risk category
- Rename columns
- Apply multiple filtering conditions

## 🛠 Technologies Used

- Python
- Pandas
- NumPy
- Jupyter Notebook
- Renaming columns

This project is part of my learning journey in data analysis for healthcare and serves as a foundation for future AI-based cardiology projects.
